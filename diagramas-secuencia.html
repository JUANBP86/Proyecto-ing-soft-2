Sistema de Gestión de Restaurante · Ingeniería de Software II · Sprint 1

Diagrama 1 – Inicio de Sesión

Flujo desde que el usuario abre el login hasta que accede a su panel según su rol. 

sequenceDiagram
    actor U  as Usuario
    participant V  as login.html
    participant C  as auth.py
    participant FL as Flask-Login
    participant M  as usuario.py
    participant BD as BD

    U  ->> V  : GET /login
    V  -->> U : Muestra formulario

    U  ->> C  : POST /login {email, password}

    loop Busca en Administrador → Mesero → Cocina → Cliente
        C  ->> BD : SELECT WHERE email=? AND activo=True
        BD -->> C  : usuario | None
    end

    C  ->> M  : check_password(password)
    M  -->> C  : True / False

    alt Credenciales incorrectas
        C  -->> U : flash "Credenciales incorrectas"
    else Credenciales correctas
        C  ->> FL : login_user(usuario)
        FL -->> C  : Sesión creada (cookie)
        C  -->> U : redirect → /dashboard

        alt rol = mesero
            U  ->> C  : GET /mesero/
        else rol = cocina
            U  ->> C  : GET /cocina/
        else rol = admin
            U  ->> C  : GET /admin/
        end

        C  -->> U : Panel de rol
    end

Diagrama 2 – Creación de Pedido (Mesero)

Flujo desde que el mesero abre el formulario hasta que el pedido queda guardado en BD con estado "pendiente". 

sequenceDiagram
    actor Me as Mesero
    participant V  as nuevo_pedido.html
    participant C  as mesero.py
    participant Mo as Modelos
    participant ORM as SQLAlchemy
    participant BD  as BD

    Me ->> C  : GET /mesero/nuevo-pedido
    C  ->> ORM : query mesas, categorías, productos
    ORM ->> BD : SELECT disponibles y activos
    BD  -->> ORM : listas de registros
    ORM -->> C  : objetos Python
    C  -->> V  : nuevo_pedido.html
    V  -->> Me : Formulario con datos

    Me ->> C  : POST {tipo, mesa_id, productos[], cantidades[]}

    alt Sin productos seleccionados
        C  -->> Me : flash "Debe agregar al menos un producto"
    else Con productos
        C  ->> ORM : Pedido(tipo, mesero_id) + flush()
        ORM ->> BD  : INSERT INTO pedidos → retorna pedido.id

        loop Por cada producto
            C  ->> ORM : DetallePedido(pedido_id, prod_id, cant, subtotal)
            ORM ->> BD  : INSERT INTO detalle_pedidos
        end

        opt tipo = salon AND mesa_id provisto
            C  ->> ORM : PedidoMesa + mesa.estado = ocupada
            ORM ->> BD  : INSERT pedido_mesa · UPDATE mesas
        end

        C  ->> ORM : calcular_total() + session.commit()
        ORM ->> BD  : UPDATE pedidos SET total · COMMIT
        BD  -->> C  : OK

        C  -->> Me : flash "Pedido #N creado" + redirect /mesero/
    end
